# MAYDAY — морская спасательная служба

Атмосферная игра на three.js про вертолёт морской спасательной службы. Вид сверху, как с дрона сопровождения:
ночной шторм, смерчи, волны-убийцы, туман и люди в оранжевых жилетах, которых нужно найти и поднять лебёдкой.

Всё процедурное: модели, текстуры, шум воды, звук и музыка генерируются в коде. Никаких внешних ассетов, сборки и
зависимостей, кроме вендоренного three.js r185 (`vendor/three`).

## Запуск

Игре нужен любой статический сервер (ES-модули не работают с `file://`):

```sh
npx http-server -c-1 .   # из корня репозитория
# затем открыть http://localhost:8080/rescue/
```

На GitHub Pages игра открывается по адресу `…/rescue/`. Нужен браузер с WebGL2.

## Управление

| действие | клавиатура / мышь | геймпад |
|---|---|---|
| полёт | W A S D / стрелки | левый стик |
| набор / снижение | E, R, PageUp / Q, F, PageDown, колесо мыши | RT / LT |
| высота 15 / 40 / 90 м | 1 / 2 / 3 | D-pad ↑ ↓ |
| лебёдка (держать) | Пробел | A |
| прожектор (наводится курсором) | L | X, правый стик |
| фальшфейер к курсору | G, ЛКМ | B |
| сброс плота | C, ПКМ | D-pad → |
| громкоговоритель | H | Y |
| форсаж | Shift | LB |
| карта (держать) | Tab, M | View |
| зум камеры | Z | RB |
| пауза | Esc, P | Start |

Привязки по `event.code`, поэтому раскладка ЙЦУКЕН работает. Ctrl не используется: Ctrl+W закрыл бы вкладку.

## Что внутри

- **Кампания «Операции»:** 8 операций и бонусная 9★, от штиля у маяка до глаза бури с торнадо. Режим **«Смена»**:
  бесконечное дежурство с нарастающей погодой и рекордами.
- **Погода:** 8 пресетов (штиль, пасмурно, шквал, шторм, ночной шторм, туман, закат после шторма, лунная ночь).
  Переходы ступенчатые, фронт идёт по морю, порывы видны на воде и толкают вертолёт.
- **Опасности:** водяные смерчи (5 стадий), торнадо, волны-убийцы, водовороты, молнии с телеграфом, град,
  нисходящие потоки.
- **Спасение:** поиск по сигналам (ракеты, дым, стробы, свистки, EPIRB, громкоговоритель), висение и лебёдка с
  маятником троса, салон на 6 мест, доставка на маяк, «Арктур» или буровую, топливо и риска «бинго».
- **Звук:** процедурный WebAudio: ротор, турбина, ветер, дождь, гром, лебёдка, тревоги, генеративная музыка и
  радиопереговоры экипажа с «бормотанием», синхронным субтитрам.
- **Доступность:** режим «Меньше вспышек», «Меньше движения», метки для дальтоников, масштаб текста и HUD.

## Структура

```
rescue/
  index.html, style.css     страница и importmap
  DESIGN.md                 дизайн-документ: вид, ощущения, числа
  src/main.js               загрузка систем, общий ctx, главный цикл
  src/CONTRACT.md           интерфейсы и события между системами
  src/core/                 ввод, настройки, шум и общий визуальный слой (look.js), выветривание, заглушки
  src/systems/<name>.js     системы: weather, ocean, world, hazards, heli, survivors, fx,
                            camera, radio, mission, audio, hud, post (+ вспомогательные папки)
  src/ui/                   DOM-интерфейс и hud.css
  vendor/three/             three.js r185 и нужные postprocessing-аддоны
```

Каждая система живёт в своём файле и общается с остальными через `ctx` и шину событий (`src/CONTRACT.md`). Если модуль
не загрузился, `main.js` подставляет заглушку из `src/core/stubs.js`, и игра продолжает работать.

## Параметры URL для отладки

| параметр | что делает |
|---|---|
| `?autostart` | сразу в полёт, без меню |
| `?mission=N` / `?mission=endless` | операция N (с нуля) / «Смена» |
| `?weather=storm` | принудительный пресет погоды |
| `?tod=0.8` | время суток |
| `?quality=low\|medium\|high` | качество графики |
| `?nohud` | без интерфейса (для скриншотов) |
| `?debug` | панель FPS и состояния |
| `?only=ocean,weather` / `?stub=audio` | изолировать системы заглушками |

В консоли браузера доступен `window.__game`: например, `__game.weather.setPreset('nightStorm', 0)` или
`__game.hazards.spawn('waterspout', {x: 60, z: -40})`.
