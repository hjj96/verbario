# Мой холодильник

Приложение и виджет для iOS по «Книге концепции» (ноябрь 2026).
Холодильник на домашнем экране, который человек оформляет своими фотографиями,
вырезками, записками и магнитиками.

Визуальная основа: **A02 «Личная галерея»** с ретро-дверцей из серии B
(**B01 «Стальной ретро»** по умолчанию, B02 и B03 доступны как отделки корпуса в настройках).

## Как запустить

Нужны **Xcode 16 или новее** (проект использует синхронизируемые папки) и iPhone с **iOS 17+**.

1. Откройте `MyFridge/MyFridge.xcodeproj`.
2. Выберите проект **MyFridge** → вкладка **Build Settings** → найдите `BUNDLE_ID_PREFIX`
   и замените `com.example` на свой префикс, например `com.ivanov`.
   Из него собираются идентификаторы приложения, виджета и общей App Group
   (`group.<префикс>.myfridge`). Менять их нужно только здесь.
3. Для обеих целей (**MyFridge** и **FridgeWidgetExtension**) на вкладке
   **Signing & Capabilities** выберите свою команду (Team). Автоматическая подпись
   сама зарегистрирует App Group.
4. Запустите схему **MyFridge** на iPhone.
5. Добавьте виджет: удерживайте домашний экран → «Изменить» → «Добавить виджет» →
   «Холодильник». В приложении есть такая же инструкция (Настройки → Виджет).

Вырезание объекта работает только на настоящем устройстве: в симуляторе Vision не
выделяет объекты, и приложение предлагает обычную фотокарточку.

## Как устроено

Приложение создаёт, виджет показывает (концепция, стр. 21).

- `Shared/` — код, общий для приложения и виджета: модель, хранилище и вся отрисовка
  дверцы, предметов и креплений. Поэтому редактор и виджет выглядят одинаково.
- `App/` — редактор, создание фотомагнитов и записок, коллекция, настройки.
- `Widget/` — виджет WidgetKit.

Композиция хранится в общем контейнере App Group: `state.json` (предметы коллекции
и их расположение на дверце) и папка `Images` с подготовленными изображениями.
Каждое фото сохраняется в двух размерах: до 1400 px для редактора и до 520 px для
виджета, чтобы он укладывался в лимит памяти. После сохранения приложение просит
WidgetKit перезагрузить виджет; сам виджет ничего не обновляет по таймеру.

Положение, размер и поворот предметов хранятся в долях дверцы, поэтому одна
композиция одинаково ложится на маленький и большой виджет.

## Если проект не открывается

Файл проекта собран вручную. Если ваша версия Xcode его не примет, установите
[XcodeGen](https://github.com/yonaskolb/XcodeGen) и выполните в папке `MyFridge`:

```sh
xcodegen
```

Команда пересоздаст `MyFridge.xcodeproj` из `project.yml` с теми же настройками.
